# نسخه V9 — علامت‌گذاری بخش‌های ناتمام آزادگذر

این نسخه **روی V8** ساخته شده است. هدفش پیاده‌سازی سرویس‌های جدید نیست؛ هرجا فرانت قبلاً عملیات ناموجود را موفق نشان می‌داد یا دادهٔ ساختگی را شبیه اطلاعات واقعی عرضه می‌کرد، اکنون وضعیت روشن و غیرگمراه‌کننده دارد.

## قابلیت‌هایی که غیرفعال نشده‌اند

ثبت‌نام/ورود، فهرست و جزئیات آگهی‌های واقعی، ثبت/ویرایش آگهی، علاقه‌مندی‌ها، مقایسه، ثبت و پیگیری درخواست‌های خدمات، پنل کارشناس، فهرست کاربران مدیر، داده‌های کسب‌وکار و ثبت **درخواست** ارتقای نمایندگی همچنان از API استفاده می‌کنند. «درخواست‌های من» پنل خریدار هم اکنون به فهرست واقعی درخواست‌های خدمات وصل است.

فایل‌های قدیمی پیش‌نمایش در کد نگه داشته شده‌اند تا طراحی‌های اولیه از دست نروند، ولی مسیرهای ناتمام به آن‌ها نمی‌رسند. بازکردن صفحهٔ به‌زودی هیچ عملیات ثبت، خرید یا پیام‌رسانی انجام نمی‌دهد.

## اعمال تغییر روی V8 در Windows / PowerShell

بسته `karvo-v9-status-patch.zip` فقط فایل‌های تغییرکرده را دارد و باید روی کد V8 اعمال شود. ابتدا فایل ZIP را در یک پوشهٔ جدا باز کنید و تغییرات محلی پروژه را پشتیبان بگیرید؛ `.env.dev`، `.env.local`، media و داده‌های Docker را بازنویسی نکنید.

```powershell
Set-Location D:\zeroteam\karvo
Test-Path .\frontend\src\lib\admin-users-api.ts  # برای V8 باید True باشد
$archive = 'D:\Downloads\karvo-v9-status-patch.zip'  # مسیر دانلود واقعی را وارد کنید
Test-Path -LiteralPath $archive
$stage = 'D:\zeroteam\karvo-v9-review'
Expand-Archive -LiteralPath $archive -DestinationPath $stage
Test-Path -LiteralPath "$stage\frontend\src\lib\feature-status.ts"
```

پس از مقایسه و پشتیبان‌گیری از فایل‌هایی که خودتان تغییر داده‌اید، فایل‌های داخل `frontend` پوشهٔ بازشده را با همان ساختار پوشه‌ها در `D:\zeroteam\karvo\frontend` ادغام کنید. بستهٔ کامل `karvo-v9-status-complete.zip` هم برای بررسی همهٔ فایل‌ها موجود است؛ آن را **مستقیماً روی پروژهٔ جاری استخراج نکنید**. در این نسخه migration یا تغییر بک‌اند نداریم.

کنترل بعد از نصب (در ریشهٔ پروژه):

```powershell
docker compose -f compose.yaml -f compose.dev.yaml ps
Set-Location .\frontend
npm ci
npm test
npm run lint
npx tsc --noEmit
npm run build
npm run dev
```

برای کنترل کامل backend/frontend در V8/V9، پس از برگشت به ریشهٔ پروژه و اطمینان از وجود اسکریپت:

```powershell
Set-Location D:\zeroteam\karvo
Test-Path .\run-quality.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\run-quality.ps1 -SkipInstall
```

گزینهٔ `-SkipInstall` فقط وقتی مناسب است که `npm ci` همین بالا موفق شده باشد. `docker compose down -v` را اجرا نکنید؛ volume دیتابیس را حذف می‌کند.

## نتیجهٔ تست در محیط آماده‌سازی

- فرانت‌اند: ۵ تست واحد (شامل کنترل مسیرهای به‌زودی)، ESLint، TypeScript و production build موفق.
- بک‌اند این نسخه دست‌نخورده است. آزمون‌های مستقل سرویس در این محیط اجرا شدند؛ integrationهای PostgreSQL/Redis/Celery نیاز به Docker روی سیستم شما دارند.
