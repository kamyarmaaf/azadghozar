# پیام‌رسانی بلادرنگ

پس از نصب و اجرای بک‌اند به‌روز و مهاجرت دیتابیس، در حالت توسعه فرانت را با `npm ci` و `npm run dev` اجرا کنید. برای تغییر مبدأ API، مقدار `NEXT_PUBLIC_API_BASE_URL` را در `.env.local` قرار دهید؛ نمونه در `.env.local.example` موجود است.

بخش پیام‌ها در داشبورد خریدار، فروشنده و نمایشگاه/نمایندگی و پنجرهٔ «پیام به صاحب آگهی» از WebSocket برای دریافت فوری پیام استفاده می‌کنند. ارسال و تاریخچهٔ پیام‌ها از API انجام می‌شود. وضعیت اتصال کنار فهرست گفتگوها دیده می‌شود. پس از قطع ارتباط، فرانت دوباره وصل می‌شود و پیام‌های احتمالی از دست‌رفته را از سرور می‌خواند.

آدرس WebSocket به‌طور پیش‌فرض از مبدأ `NEXT_PUBLIC_API_BASE_URL` و مسیر `/ws/catalog/messages/` ساخته می‌شود. اگر آن مسیر روی مبدأ دیگری قرار دارد، پیش از build متغیر `NEXT_PUBLIC_WS_BASE_URL` را روی مبدأ آن تنظیم کنید. پروکسی سرور باید اتصال‌های WebSocket را به Django ASGI/Daphne برساند؛ راهنمای نمونه در `MESSAGING-FA.md` فایل بک‌اند است.
